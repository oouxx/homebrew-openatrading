# Homebrew OpenATrading Tap

通过 Homebrew Cask 安装 OpenATrading。

## 安装

```bash
brew tap oouxx/openatrading
brew install --cask openatrading
```

## 升级

```bash
brew update
brew upgrade --cask openatrading
```

## 卸载

```bash
brew uninstall --cask openatrading
brew untap oouxx/openatrading
```
